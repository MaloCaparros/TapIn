TapIn Poker Menteur · Roulette

Annonce, bluffe… et prie pour que le barillet soit vide.

Règles
  • Chaque joueur reçoit 3 cartes cachées.
  • À tour de rôle, on annonce une combinaison de poker qui existerait parmi toutes les cartes de la table. Chaque annonce doit être plus forte que la précédente.
  • Au lieu d'enchérir, crie « Menteur ! » : on retourne tout. Si la combinaison existe, l'accusateur perd ; sinon, c'est l'annonceur.
  • Le perdant tire avec son revolver (6 chambres, 1 balle). Le dernier survivant gagne.

Carte haute < Paire < Double paire < Brelan < Suite < Couleur < Full < Carré < Quinte flush. À type égal, la hauteur départage (couleurs : ♣ < ♦ < ♥ < ♠).
